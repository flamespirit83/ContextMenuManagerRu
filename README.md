# ContextMenuManager (RU Fork)
![](Logo/Logo.png)
------
> 🖱️ Программа для управления контекстным меню Windows — Полностью локализованная русская версия.

## От автора форка (Flamespirit83)
Это мой первый личный эксперимент по созданию форка. Оригинальный проект был заброшен автором в далеком 2021 году. Меня категорически не устраивало, что глубокие настройки (дополнительные правила, сторонние утилиты, улучшение меню) оставались на китайском языке, поэтому я перевел их для собственного удобства.

* **Что изменено:** Полностью переведены на русский язык внутренние словари и скрытые меню, до которых не добралась базовая локализация.
* **Особенности перевода:** При скачивании архива с готовыми конфигами программа сразу стартует на русском. Если запустить голый exe-файл, интерфейс по умолчанию сбросится на английский и предложит скачать язык оболочки. Однако переведенные мной внутренние словари (правила, сторонние программы) всё равно останутся русскими при любом выбранном языке интерфейса.
* **Поддержка:** Форк сделан по принципу «для себя, пользуйтесь на здоровье». Я не гарантирую, что буду заходить на GitHub в ближайший месяц, год и вообще замечу ваши баг-репорты или предложения. Если вам очень нужен оригинал со старыми китайскими хвостами — ссылки на него оставлены внизу.

## Скачивание программы
* **[Скачать русскую версию (Последний релиз)][Latest-RU]**
* **Инструкция:** скачайте ZIP-архив из раздела Assets и распакуйте всё в одну папку. Запускайте `ContextMenuManager.exe`.

## Основные возможности (от оригинального автора)
* Включение и отключение пунктов контекстного меню для файлов, папок, меню «Создать», «Отправить», «Открыть с помощью», пользовательских форматов файлов, меню WinX и других.
* Переименование, смена иконок, переход к ветке реестра, переход к расположению файла.
* Добавление пользовательских пунктов и команд в контекстное меню.
* Поддерживается Windows 10, 8.1, 8, 7, Vista (требуется установленный .NET Framework).

## Важные замечания
* Программа выполняет множество операций в реестре и файловой системе. Эти действия чувствительны и могут быть ложно распознаны антивирусами (например, Windows Defender) как вредоносные. Добавьте программу в исключения.
* Разные программы для управления контекстным меню используют различные методы отключения. Не рекомендуется использовать несколько таких утилит одновременно во избежание конфликтов.
