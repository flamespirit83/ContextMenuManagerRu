# ContextMenuManager
![](Logo/Logo.png)
------
> 🖱️ Программа для управления контекстным меню Windows

## Скачивание программы
* [Последняя версия][Latest]<br>
  [GitHub Releases][GitHub Releases]<br>
  [Gitee Releases][Gitee Releases]<br>
* Инструкция: в списке Assets скачайте zip (рекомендуется) или exe-файл.
* Версии .NET: программа доступна для .NET 3.5 и .NET 4.0, обе подходят для Windows 10, 8.1, 8, 7, Vista.<br>
  Windows 7 поставляется с .NET 3.5, Windows 8/8.1/10 — с .NET 4.0 и выше, в Vista нет ни .NET 3.5, ни .NET 4.0.<br>
  Если нужная версия уже установлена, программа запустится сразу; если нет — установите соответствующую версию [.NET Framework][.NET Framework].

## Основные возможности
* Включение и отключение пунктов контекстного меню для файлов, папок, меню «Создать», «Отправить», «Открыть с помощью», пользовательских форматов файлов, браузера IE, меню WinX и других.
* Переименование, смена иконок, переход к ветке реестра, переход к расположению файла, безвозвратное удаление для пунктов меню в перечисленных сценариях.
* Добавление пользовательских пунктов и команд в контекстное меню для указанных сценариев.

## Совместимость
* Поддерживается Windows 10, 8.1, 8, 7, Vista.
* Поддерживаются 64-битные и 32-битные версии ОС.
* Поддерживаются экраны с высоким разрешением (рекомендуемый масштаб отображения — 150%).
* Программа поддерживает интернационализацию (многоязычный интерфейс); приветствуются пользовательские словари перевода.

## Важные замечания
* Программа выполняет множество операций чтения, записи, удаления и изменения в реестре и файловой системе — эти действия чувствительны и могут быть ложно распознаны антивирусами (например, Windows Defender) как вредоносные. В таком случае добавьте программу в исключения.

* Некоторые специальные пункты меню могут не отображаться непосредственно в контекстном меню из-за внешних факторов, но в программе они будут помечены как включённые согласно общим правилам — это нормально.

* Разные программы для управления контекстным меню используют различные методы отключения. Не рекомендуется использовать несколько таких программ одновременно.<br>
  Большинство программ используют простое резервное копирование и удаление, тогда как данная программа по возможности скрывает пункты через системные параметры.<br>
  Пункты, отключённые другими программами, сначала восстановите с их помощью, иначе они могут не отображаться в этой программе.

* Программа не предназначена для очистки следов неполностью удалённых приложений, но помогает быстро найти связанные с пунктами меню ветки реестра и файлы, чтобы вы могли выполнить нужные действия самостоятельно. Если вы неопытный пользователь, рекомендуется использовать только функцию включения/отключения.
